系统入口

CHROME / EDGE

自动登录扩展

扩展在访问者自己的 Chrome 或 Edge 中运行。每个浏览器首次填写并保存所需系统密码一次；以后从系统入口打开网页系统时，扩展会自动填写并提交登录表单。密码只保存在当前浏览器，不会同步到其他设备。

下载扩展 ZIP 返回系统入口

安装与设置

  1. 解压下载的 ZIP，找到包含 manifest.json 的 archive-demo-login-extension 文件夹。
  2. 在 Chrome 打开 chrome://extensions，或在 Edge 打开 edge://extensions，启用“开发人员模式”。
  3. 选择“加载解压缩的扩展”，加载上一步的文件夹。
  4. 打开扩展详情中的“扩展程序选项”，检查账号，填写需要演示的系统密码并保存一次。
  5. 返回系统入口并点击“系统演示”。登录页会自动填写；遇到验证码、短信码或二次验证时，请按页面提示人工处理。

连接要求

六个公网网页系统可从外网打开。密集架位于单位内网，使用者电脑必须连接单位网络或获准的 VPN/隧道。艾搜是 Windows 客户端，浏览器扩展不能安装或启动该客户端。

目标系统当前使用 HTTP，登录密码传输未加密。只在可信网络中演示；不要把本机密码或含真实凭据的文件上传到公开仓库。

扩展不会绕过验证码或二次验证。
