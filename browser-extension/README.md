# 档案演示自动登录扩展

扩展在 Chrome 或 Edge 中运行。GitHub Pages 提供无凭据的扩展 ZIP 和安装说明。安装并保存账号密码一次后，从 Pages 点击系统入口，扩展会在目标登录页自动填写并提交。密码保存在当前浏览器的扩展本地存储中，不进入本仓库，也不会上传到 GitHub。

## 安装

1. 解压 `archive-demo-login-extension.zip`，找到其中的 `archive-demo-login-extension` 文件夹。
2. 打开 `chrome://extensions`（Chrome）或 `edge://extensions`（Edge）。
3. 打开“开发人员模式”，点“加载解压缩的扩展”，选择包含 `manifest.json` 的 `archive-demo-login-extension` 文件夹。
4. 打开扩展设置，在需要演示的系统中填写账号密码并保存。常用账号已预填；密码必须由使用者或管理员本机填写。
5. 保存后重新打开 GitHub Pages，再点系统卡片。扩展只对配置的系统域名运行。单个标签页最多自动提交一次；登录失败后如需重试，请新开标签页。

## 支持范围

支持智能文件柜、AI 辅助数字化扫描加工、档案数字化管理、密集架一体化平台、综合档案管理、干部人事档案和综合单机版档案这七个网页系统。六个公网系统从 Pages 直接打开；密集架入口打开对应内网地址，访问者的电脑必须先连接单位网络或获准的 VPN/隧道，扩展不会代替网络连接。

艾搜文件智能体是 Windows 客户端，浏览器扩展不能安装或启动它。客户端仍须预先安装并通过本机程序或授权桌面运行。

遇到验证码、滑块、短信码或二次验证时，扩展会停止提交并提示人工处理，不会尝试绕过。目标站点页面改版后，可在设置页为该站点填写账号、密码和登录按钮 CSS 选择器。

干部人事档案系统已按登录页配置 `#loginname`、`#password` 和 `#to-recover`。综合单机版登录页含隐藏旧表单与可见新表单，并复用 `txtaccount`、`txtpassword`、`btlogin` ID；扩展会在重复匹配中选取当前可见元素。

## 账号安全

不要把包含真实密码的配置文件、扩展目录或打包文件上传至公开 GitHub。扩展包不含密码。公司若要免去每位使用者的安装与配置步骤，需要 IT 通过浏览器管理策略预装扩展并配置本机凭据；普通公开网页无法静默安装扩展。

目标系统当前使用 HTTP。扩展填入的密码会提交给目标站点，HTTP 链路不加密；外网使用前应确认站点方提供 HTTPS，或仅在可信网络中演示。
